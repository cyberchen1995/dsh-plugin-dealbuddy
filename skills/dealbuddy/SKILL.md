# DealBuddy

> R1 骨架版：仅覆盖本轮已实现的只读能力。完整工作流与文案在 R4 补齐。

## Overview

DealBuddy 把购物比价的过程留成记录。商品事实来自用户在真实详情页上的手动采集，
插件负责保存会话、商品与报告；追问由当前对话直接承担，不需要额外配置模型。

## 本轮可用工具

- `dealbuddy_list_sessions`：列出本机会话摘要（品类、商品数、是否已有报告、当前会话指针）。

## 红线

- 价格字段 `estimated_payable` 一律称「估算应付」，不得称结算价、到手价或最低价。
- 报告是四槽摘要，不是候选全集：合规但既非最优也非最便宜的商品不会出现在报告里。
- 不调用平台 API、不做浏览器自动化、不读取或导出 Cookie，不进入购物车、结算、下单或支付环节。
